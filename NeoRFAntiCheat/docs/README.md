## 一句话总览

- **原生检测**：数据包/事件监听，服务端独立判定，不依赖客户端上报。
- **/report 强制查端**：Fabric 自定义 Payload 请求目标客户端 ModList，与黑名单比对。
- **阶梯封禁**：UUID 为主键，首次有效封禁 15 天，二次有效封禁永久，误封标记不计次数。
