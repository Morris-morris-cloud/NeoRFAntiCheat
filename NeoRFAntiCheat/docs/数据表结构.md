# 数据表结构

NeoRFAntiCheat 的持久化由 `StorageProvider` 抽象，默认实现 `JsonStorage`
（单文件 JSON，原子写入），并预留 H2 扩展（`DatabaseHelper`）。

## 1. 核心实体关系

```
玩家 (UUID 主键)
   │ 1
   ▼
PlayerBanState ── validBanCount 有效封禁次数（阶梯判定依据）
   │ 1
   ▼ N
BanRecord      一条封禁/解除历史记录（含证据快照）
```

## 2. PlayerBanState（玩家封禁状态）

| 字段 | 类型 | 说明 |
|------|------|------|
| `validBanCount` | int | 有效封禁次数，只用于阶梯判定 |
| `records` | List\<BanRecord\> | 该玩家全部封禁记录 |

## 3. BanRecord（封禁记录）

| 字段 | 类型 | 说明 |
|------|------|------|
| `uuid` | UUID | 玩家 UUID（主键关联） |
| `name` | String | 玩家名（快照，可能改名） |
| `status` | BanStatus | ACTIVE / EXPIRED / FALSE_POSITIVE / MANUAL_UNBAN |
| `checkName` | String | 触发检测（fly / speed / report-mod 等） |
| `banStartMs` | long | 封禁开始时间戳 |
| `banEndMs` | long | 结束时间戳，`-1` = 永久 |
| `durationMs` | long | 封禁时长，`-1` = 永久 |
| `automatic` | boolean | 是否自动封禁 |
| `evidence` | Snapshot | 证据快照 |
| `createdAtMs` | long | 记录创建时间 |

## 4. Snapshot（证据快照）

| 字段 | 类型 | 说明 |
|------|------|------|
| `checkName` | String | 触发检测 |
| `uuid` / `name` | String | 玩家标识 |
| `x` / `y` / `z` | double | 触发坐标 |
| `dimension` | String | 维度注册名 |
| `onGround` | boolean | 是否着地 |
| `velocityY` | double | 垂直速度 |
| `tickTime` | long | 服务端 tick 计数 |
| `ping` | int | 玩家 ping（ms） |
| `yaw` / `pitch` | float | 视角 |
| `detail` | String | 人类可读细节 |

## 5. ReportRecord（举报单）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 举报单唯一 id |
| `reporterUuid` / `reporterName` | UUID / String | 举报人 |
| `targetUuid` / `targetName` | UUID / String | 被举报人 |
| `remark` | String | 备注 |
| `createdAtMs` | long | 举报时间 |
| `checkStatus` | CheckClientStatus | PENDING / SUCCESS / TIMEOUT / NON_FABRIC |
| `matchedMods` | List\<String\> | 命中黑名单的 modId |
| `reportedModIds` | List\<String\> | 客户端上报的全部 modId |
| `verdict` | String | 核验结论 |

## 6. 存储实现

### 6.1 JSON（默认）

- UUID 封禁路径：`config/neorf-anticheat-data/bans.json`
- 玩家名封禁路径：`config/neorf-anticheat-data/name-bans.json`，以小写玩家名为键，不依赖 UUID。
- 序列化：Gson，字段名与上表一致。
- 写入：**原子写**（先写 `.tmp` 再重命名），避免写一半损坏。
- 损坏兜底：加载失败返回空 Map，绝不让服务器崩溃。

### 6.2 H2（预留扩展）

切换 `StorageProvider` 为 H2 实现时，建议建表（见 `DatabaseHelper` 注释）：

```sql
CREATE TABLE IF NOT EXISTS bans (
  uuid        VARCHAR(36) PRIMARY KEY,
  valid_count INT         NOT NULL DEFAULT 0
);

CREATE TABLE IF NOT EXISTS ban_records (
  id          BIGINT AUTO_INCREMENT PRIMARY KEY,
  uuid        VARCHAR(36) NOT NULL,
  check_name  VARCHAR(64),
  status      VARCHAR(32),
  ban_start   BIGINT,
  ban_end     BIGINT,
  evidence    TEXT,
  created_at  BIGINT
);

CREATE TABLE IF NOT EXISTS reports (
  id            VARCHAR(32) PRIMARY KEY,
  reporter      VARCHAR(36),
  target        VARCHAR(36),
  remark        TEXT,
  created_at    BIGINT,
  check_status  VARCHAR(32),
  verdict       TEXT
);
```

> 说明：当前版本举报单（reports）保存在内存中，未持久化；
> 如需跨重启保留，可像封禁数据一样接入 StorageProvider。
