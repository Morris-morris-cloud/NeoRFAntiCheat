# 部署配置说明

## 1. 环境要求

- Java 25+
- Minecraft 26.1
- Fabric Loader 0.20.1 与 Fabric API 0.145.1+26.1
- Fabric API（服务端）
- 纯服务端部署（environment = "server"）

## 2. 构建

```bash
# 进入项目目录
cd NeoRFAntiCheat

./gradlew build
```

产物：`build/libs/NeoRF-AntiCheat-1.0.1.jar`

## 3. 部署

1. 把编译好的 jar 放入服务端 `mods/` 目录。
2. 首次启动会在 `config/` 生成配置文件和封禁数据目录：
   - `neorf-ac-config.json` —— 反作弊配置（可编辑，改后 `/NeoRF reload`）
  - `neorf-anticheat-data/bans.json` —— UUID 封禁数据（自动维护）
  - `neorf-anticheat-data/name-bans.json` —— 玩家名封禁数据（自动维护）
3. 重启或 `/NeoRF reload` 生效。

## 5. 指令清单

### /report（玩家及控制台可用）
```
/report <target> [remark]     举报玩家并触发强制查端
```
- 玩家执行时有 5 分钟冷却（内存缓存，重启清空）；服务端控制台执行不受冷却限制。

### /NeoRF（管理员，权限 2）
```
/NeoRF baninfo <player/uuid>   查看封禁历史、有效计数、每条记录状态
/NeoRF ban <player-name|uuid> [reason]  按玩家名或 UUID 手动封禁
/NeoRF unban <player-name|uuid>         解除对应封禁
/NeoRF unbanf <player-name|uuid>        以误封方式解除
/NeoRF clearcount <uuid>       清零有效封禁计数（兜底运维）
/NeoRF reportlist              列出全部举报单、查端状态、核验结果
/NeoRF reload                  重载配置（黑名单、阈值、超时、冷却）
```

## 6. 白名单配置示例

```json
"whitelist": {
  "exemptUuids": ["xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"],
  "regions": [
    {
      "name": "spawn",
      "world": "minecraft:overworld",
      "minX": -100, "minY": -64, "minZ": -100,
      "maxX": 100, "maxY": 320, "maxZ": 100,
      "disabledChecks": ["fly", "speed"]
    }
  ]
}
```
- OP/管理员权限不会豁免检测；只有显式 UUID 白名单或区域白名单会豁免对应检测。
- spawn 矩形区域内关闭 fly/speed 检测。

## 7. 运维建议

1. **先低敏上线**：上线初期把各 `violationsToBan` 调高、阈值放宽，观察 1~2 周误报率再收紧。
2. **误封复核**：玩家申诉时用 `/NeoRF baninfo` 看证据快照，确属误判用
  `/NeoRF unbanf <uuid>`，误封不叠加计数。
3. **定期备份**：定期备份 `bans.json` 和 `name-bans.json`；迁移用 `/NeoRF clearcount` 处理计数异常。
4. **版本升级**：升级 MC 版本时同步更新 gradle.properties 中的版本号，并回归检测阈值。

## 8. 验证

- `./gradlew build` 通过即编译成功。

  （覆盖阶梯、冷却、MathUtil），通过 `./gradlew test` 运行。
